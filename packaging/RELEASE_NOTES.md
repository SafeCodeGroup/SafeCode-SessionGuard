## Downloads

| Your computer | Download |
|---|---|
| **Mac with Apple Silicon** (M1, M2, M3, M4, M5) | `SafeCodeSessionGuard-{version}-macos-apple-silicon.dmg` |
| **Mac with Intel** processor | `SafeCodeSessionGuard-{version}-macos-intel.dmg` |
| **Windows 10/11, 64-bit** (Intel / AMD) | `SafeCodeSessionGuard-{version}-windows-x64.zip` |
| **Windows 10, 32-bit** | `SafeCodeSessionGuard-{version}-windows-x86.zip` |
| **Windows 11 on ARM** (Snapdragon, Surface Pro X) | `SafeCodeSessionGuard-{version}-windows-arm64.zip` |
| **Linux 64-bit PC** (Ubuntu 22.04+, Debian 12+, Fedora, Arch, Mint 21+) | `SafeCodeSessionGuard-{version}-linux-x86_64.tar.gz` |
| **Linux 64-bit ARM** (Raspberry Pi 3/4/5 with 64-bit OS, ARM servers) | `SafeCodeSessionGuard-{version}-linux-aarch64.tar.gz` |
| **Raspberry Pi OS 32-bit** (Pi 2/3/4/5, Bookworm or newer) | `SafeCodeSessionGuard-{version}-linux-armv7l.tar.gz` |
| **Linux 32-bit PC** (Debian 12+ i386) | `SafeCodeSessionGuard-{version}-linux-i686.tar.gz` |

The `.zip` files for macOS contain the same app as the `.dmg`.

**Which one do I need?** Mac: Apple menu → About This Mac ("Chip: Apple M…" = Apple Silicon).
Windows: Settings → System → About → System type. Linux: run `uname -m`.

Install instructions: see the [README](https://github.com/SafeCodeGroup/SafeCode-SessionGuard#install).
Every file was built natively for its CPU and passed an automated self-test and launch test.
